## Done

Recorded so a later review does not raise them again.

- Toolbar and Cut out review (2026-10-08). No critical or high. Raised and rejected: "`Graphics.FillRoundedRectangle` does not exist, build break": it is in System.Drawing since .NET 9, and the build and 121 tests pass. "`Cut.Apply` exact copy unverified": the pixel test covers both directions and an edge band and passes. "Icon code points unchecked": each was rendered from SegoeIcons.ttf and chosen by eye.

- Low items, round 5 (2026-10-08), each batch reviewed by a second agent. Folder: a link to a share now gets the network warning (walked root-down, since walking up reached the share: a review high, fixed before commit); the picker never starts in a network folder; `\\?\C:\` folders open fine in explorer (tested), nothing to change. Images: size checked on the handle that is read, so a growing file cannot pass the limit; pipes and devices refused. Scrolling: the lost-not-end rule has a unit test. Corners: snapped is `IsWindowArranged`, not a guess from the work area.
- Live scrolling suite still to rerun on the main display, from tag `live-test-base` (2a1ba67, sidebar painting removed) and then on the latest `windows`.

- Sidebar painting removed (2026-10-08): a still strip was filled with its background below the first frame, and where a 48 px strip straddled a pane edge that erased the content beside the pane (shown with a mail-style pane and a "Yes" column: "Yes" came out as "s"). Still areas now repeat, as in ShareX. This also closes the flat-gradient-sidebar and zebra-pane items.

- Fourth review (2026-10-08): `InvalidDataException` refusals from `Images.Open` crashing instead of showing a message, an Esc tap lost while waiting for a held button, the `Stitcher.Add` doc comment contradicting the code. A sticky panel with a moving highlight (docs "In this article") no longer stops being a sidebar: moved now means most of what is drawn changed, and a sidebar is repainted only in rows unchanged since the frame before, so a misjudged one repeats pixels but never erases content. The whole-width fallback's "end" is ignored when a sidebar is known. Folders with commas opened the wrong place (verified: "a,b" opened Documents); the path is now always quoted. A network screenshots folder gets a warning once on Save, not a refusal (your call). Mixed DPI tested with the main display at 125% and the panel at 100%: region captures across the boundary pixel-exact, window snap, Notepad, Edge and VS Code scrolling captures whole; editor drawn correctly at 125%.
- Fifth reviews (2026-10-08). Security: no critical or high; `\\.\UNC\` and `//host/share` folders now warned too. Correctness (one high, fixed): the new "moved" rule took a list column showing the same value on most rows ("Yes", a checkbox), scrolled by whole rows, for a sidebar and painted its cells over; a strip whose content fits the scroll as well as it fits standing still now counts as moved. Medium, fixed: blank strips counted as sidebars and turned a real end into "lost"; only sidebars with something in them count. Low, fixed: warn-once compared case-sensitively. Re-review of the fix: no critical or high; tests now also cover the tie (every cell the same).
