# Project Skills

Project-scoped skills for this repository: usage notes, coding standards,
commit/PR requirements, and any project-specific agent skills live here.

This directory (`.agents/skills/`) is canonical. Claude Code discovers it via
the `.claude/skills` pointer.

## Skills in this repository

| Skill | Use it for |
| --- | --- |
| `screenx-docs` | Writing or updating `README.md`, `docs/TECHNICAL.md` or `AGENTS.md`, and regenerating the screenshots in `docs/images` with `npm run docshots`. Covers the ASD-STE100 wording rules for the README, how the synthetic mock screenshots are produced, and the two privacy rules that keep real desktops and user names out of committed images. |
